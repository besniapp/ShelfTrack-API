# Chapter 25 — Identity: How One Document Stays Distinguishable

ShelfTrack may contain two books with the same title, several editions of the same work, or a record whose title is corrected after it is stored. Descriptive fields help humans recognize a book, but they are a poor foundation for deciding which exact database document should be updated or deleted.
