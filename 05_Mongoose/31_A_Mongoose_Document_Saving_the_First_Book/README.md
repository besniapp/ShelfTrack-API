# Chapter 31 — A Mongoose Document: Saving the First Book

A schema is only a definition until we create an actual document. The first stored book gives us a concrete place to distinguish plain JavaScript objects from Mongoose documents.

This folder accompanies Chapter 31 of *Node.js Backend Development*.

## Chapter-end reference

`code/` contains the files added or changed in this chapter. Apply them to your existing working project after following the chapter. Files not listed here continue from earlier chapters. This folder is not a complete standalone application.

- `scripts/saveFirstBook.js`

Run `node scripts/saveFirstBook.js` from your working project root. This writes one sample record; use a fresh ISBN for repeated runs after Chapter 44.
