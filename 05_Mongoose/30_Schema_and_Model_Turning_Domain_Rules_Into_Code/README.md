# Chapter 30 — Schema and Model: Turning Domain Rules Into Code

MongoDB can accept flexible documents, but ShelfTrack still has rules. A book needs a title and ISBN, copy counts cannot be negative, and the application needs one consistent way to create and query books.

This folder accompanies Chapter 30 of *Node.js Backend Development*.
