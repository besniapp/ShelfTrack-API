# Chapter 4 — Requests Ask; Responses Answer

Two actions can look similar in the interface while meaning very different things to the backend. Opening a book detail page asks for information. Reserving a copy asks the system to change shared state. HTTP messages need to make that distinction visible.

This folder accompanies Chapter 4 of *Node.js Backend Development*.
