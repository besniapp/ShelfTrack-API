# Chapter 3 — HTTP as a Conversation Between Separate Programs

A librarian can use a dashboard written by one team while the ShelfTrack API runs on another machine. Those programs do not share variables, function calls, or memory. They communicate by sending messages across a network.

This folder accompanies Chapter 3 of *Node.js Backend Development*.
