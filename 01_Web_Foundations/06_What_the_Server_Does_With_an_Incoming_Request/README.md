# Chapter 6 — What the Server Does With an Incoming Request

A request reaches ShelfTrack, but the server is not a box that automatically “knows” what the caller meant. The running application has to move that request through a sequence of decisions until one response is produced.

This folder accompanies Chapter 6 of *Node.js Backend Development*.
