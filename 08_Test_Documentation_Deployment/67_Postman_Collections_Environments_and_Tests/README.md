# Chapter 67 — Postman Collections, Environments, and Tests

Import the collection and Local environment from `postman/`. Set `baseUrl` for your running API. The collection covers the complete reference API, including Books, Members and Loans; when following the incremental Books project, run the Books requests first. The complete workflow is available in Chapter 70. Use a disposable database for create, update and delete checks.
