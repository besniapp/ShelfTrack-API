# Chapter 11 — Modules: Giving Each File One Clear Job

The first version of ShelfTrack keeps constants, helpers, startup code, and sample data in one file. It works, but every change requires navigating an increasingly crowded page.

This folder accompanies Chapter 11 of *Node.js Backend Development*.

## Chapter-end reference

`code/` contains the files added or changed in this chapter. Apply them to your existing working project after following the chapter. Files not listed here continue from earlier chapters. This folder is not a complete standalone application.

- `src/index.js`
- `src/utils/formatBook.js`

Run this module example with `node src/index.js`. It is a separate module exercise before the API server is introduced.
